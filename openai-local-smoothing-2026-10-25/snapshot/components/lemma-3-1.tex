Let $k=3$ or $4$, use $(e_0,e_1,e_2,e_3)=(1,\mathbf i,\mathbf j,\mathbf k)$, and write $z_a=\sum_{\alpha=0}^{k-1}e_\alpha z_{a\alpha}$ for $1\le a\le m$. For a real $C^2$ function $u$, define
\[
G_a(u)=\sum_\alpha e_\alpha\partial_{a\alpha}u,\qquad
H_{ab}(u)=\sum_{\alpha,\beta}e_\alpha\bar e_\beta\,
       \partial_{a\alpha}\partial_{b\beta}u,\qquad
\partial_{a\alpha}=\partial/\partial z_{a\alpha}.
\]
Then $H(u)$ is Hermitian and $\operatorname{tr}H(u)=\Delta u$. The map from the real Hessian to $H(u)$ sends the real rank-one matrix $\xi\xi^{\mathsf t}$ to $gg^*$, where $g_a=\sum_\alpha e_\alpha\xi_{a\alpha}$, and sends nonnegative real matrices to nonnegative quaternionic matrices. For real $C^2$ functions $u,v$,
\[
H(uv)=uH(v)+vH(u)+G(u)G(v)^*+G(v)G(u)^* .
\]
In four slots $H$ is covariant under quaternionic unitary changes of coordinates, and in three slots it is covariant under real orthogonal changes of the index $a$ applied in all slots. If $u$ depends only on $P\in\mathbb C_{\mathbf k}^m$ in $z_a=x_a+P_a\mathbf i$ (and is independent of the fourth slot if present), write $P_a=p_a+\mathbf k q_a$ and use
\[
\partial_{P_a}=\tfrac12(\partial_{p_a}-\mathbf k\partial_{q_a}),\qquad
\partial_{\bar P_a}=\tfrac12(\partial_{p_a}+\mathbf k\partial_{q_a}).
\]
With this convention,
\[
G_a(u)=2(\partial_{\bar P_a}u)\mathbf i,\qquad
H_{ab}(u)=4\partial_{\bar P_a}\partial_{P_b}u .
\]
For a holomorphic map $F=(F_1,\ldots,F_\ell)$ of $P$ with complex Jacobian $J_{\nu a}=\partial_{P_a}F_\nu$, one has $H(\sum_\nu|F_\nu|^2)=4J^*J$. For a smooth real function $\rho$ of the complex variables $F_\nu$, the gradient $G(\rho\circ F)$ belongs to the quaternionic image of $J^*$.
